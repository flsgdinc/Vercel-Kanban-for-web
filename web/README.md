# Kanban Mobile (веб)

Тонкий клиент на **Preact + Vite** для телефона: просмотр задач, добавление в колонку, отметка выполненными. Данные в той же таблице `kanban_boards`, что и десктоп.

## Требования

- Node.js 18+
- Тот же проект Supabase и аккаунт, что в Electron-приложении
- Доска уже загружена в облако с ПК (**↑ В облако**)

## Локальный запуск

```bash
cd kanban-app
npm run web:install

# Вариант A: .env.local (рекомендуется)
cp web/.env.example web/.env.local
# отредактируйте VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY

npm run web:dev
```

Откройте http://localhost:5173

**Вариант B:** на первом экране введите URL и anon key (сохраняются в `localStorage` браузера).

URL только корень проекта: `https://xxxx.supabase.co` (без `/rest/v1`).

## Сборка

```bash
npm run web:build
```

Статика в `web/dist/` — можно выложить на Vercel, Netlify, Cloudflare Pages.

На хостинге задайте переменные:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

## Использование с телефона

1. Откройте URL деплоя в браузере.
2. Войдите тем же email/паролем.
3. Выберите колонку, добавляйте и отмечайте задачи.
4. На ПК: **Синхронизировать** или автосинк — подтянуть изменения с телефона.

## Ограничения MVP

- Нет переноса между колонками, дедлайнов, помодоро, повторов (повтор при «выполнить» — только в десктопе).
- Last-write-wins: при одновременном редактировании ПК и телефона возможен конфликт; веб предупредит и предложит обновить из облака.
- Тема оформления (светлая/тёмная) берётся из облака и при сохранении с веба не сбрасывается — как в десктопе.
